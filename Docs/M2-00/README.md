## 核心建议与 Review 决策

先限定一个大陆城市的小样本场景；候选组合为**经授权的一个地图服务 + 景点官方公告的人工核查摘要 + 酒店/城际交通未知项和明确披露**。高德是技术首选候选，百度是替换候选，均未通过持久化与评测数据许可门槛。没有已获许可的地图来源时，只做自建合成夹具和端口设计，不自动调用。酒店动态报价不作为首批真实接入的前置依赖。

Review 需要决定：①批准 EvidenceV2/PriceScopeV2 与契约版本边界；②接受路线分项状态而非整体“已验证”承诺；③批准首个城市、许可证/快照留存门槛；④冻结评测门槛；⑤只选择一个后续切片授权。未知费用可披露确认，已知超预算、确定的时间不可行和关键硬限制不满足必须拦截；用户点击确认不能升级证据状态。
