# 供应商字段映射与M2-01a契约适配检查

核查日期：2026-11-15。只描述后续拟议映射，不修改M2-01a源码，不建立真实资源ID或发送请求。字段依据：[高德POI2.0 A01](https://developer.amap.com/api/webservice/guide/api-advanced/newpoisearch)、[百度Place3.0 B01](https://lbsyun.baidu.com/docs/webapi?title=placev3/guide/webservice-placeapiV3/interfaceDocumentV3)。未取得账户响应，所有返回格式须在授权后由严格原始DTO和实际样本验证。

## 搜索与详情动作

| 端口 | 高德候选请求映射 D/I | 百度候选请求映射 D/I |
|---|---|---|
| PlaceSource.search(PlaceQuery) | `/v5/place/text`；keyword→keywords、city/地区代码→region并city_limit=true、category经显式码表→types | `/place/v3/region`；keyword→query、城市/区县→region并region_limit=true、category经码表→type |
| PlaceSource.detail(ResourceRef, scope) | `/v5/place/detail`，provider_resource_id→id；试点一请求一ID | `/place/v3/detail`，provider_resource_id→uid；试点一请求一UID |
| 目标字段 | 只请求必要基础资料，父子POI按获准范围选择；不请求营业/价格/照片 | 只保留地点字段；即使较宽scope返回其他资料，也在规范化边界丢弃，不视为允许持久化 |

相对路径只是文档说明，不能由用户或模型传入。真实Adapter必须把HTTPS host/path、API版本、provider和凭据引用固定在可信composition root；绝不请求任意source_reference里的URL。

## 逐字段映射

下表的右侧校验/空值/ID/状态规则为EasyTravel设计推断I；供应商字段存在性为D，不表示完整率。

| M2-01a字段 | 高德候选字段 | 百度候选字段 | 规范化与边界 |
|---|---|---|---|
| ResourceRef.provider | 不从响应取得 | 不从响应取得 | 可信注册标识拟用amap_poi_v5或baidu_place_v3，与版本/账户用途绑定 |
| internal_resource_id | 无 | 无 | 服务端资源注册表分配内部UUID；不能复制供应商ID、用名称当主键或沿用synthetic的site_key派生法 |
| provider_resource_id | id | uid | 按provider命名空间保存；校验≤80及当前Identifier字符范围，不截断/改写ID；不符则schema_changed并单独Review契约扩展 |
| city / district | cityname / adname | city / area | 以行政编码校对名称，空白/缺失按字段处理；直辖市/区县需规范名称映射，不从自由文本猜地区 |
| name | name | name | 必填，≤200；别名/搜索词差异需消歧，不能偷偷改名使子串检查通过 |
| address / address_complete | address | address | 空值→null；非空也不自动完整。按获准规则/人工核对标完整，未满足则false并列missing_fields |
| category | type/typecode | detail_info.tag或classified_poi_tag等明确类别字段 | 固定码表/版本映射；缺类别不能编造“景点”，不符合必要字段则schema_changed或人工补证 |
| coordinates.longitude/latitude | location字符串拆为数值 | location.lng / location.lat | 确认经纬顺序、有限值与范围；空/缺→null。供应商字符串可在Infrastructure严格解析，Domain继续拒绝字符串数字 |
| coordinates.crs | 北京范围采用GCJ-02，经产品版本/通用体系资料确认 | 显式ret_coordtype=gcj02ll时GCJ-02；否则按明确文档语义BD-09 | 坐标转换不是重命名CRS；无法确定则null。首轮选定一种原生输出，不启用转换服务 |
| entrance | 子POI关系仅作线索 | navi_location仅作引导点线索 | 无可确认的入口ID/方向/坐标语义时null；不造main入口，不把中心点/上车点当已核验入口 |
| source_reference.reference | 无Key的本地观测引用+provider/ID | 同左 | ≤300，采用本地稳定引用；不存完整带Key的请求URL、供应商任意跳转或异常原文 |
| SourceMetadata.environment | 不从响应取得 | 不从响应取得 | 只能由服务端注册live；真实接口录制为replay、沙盒为sandbox，不能混用 |
| SourceMetadata.observed_at | 响应无可靠统一业务更新时间保证 | 同左 | 服务端实际收到本次观察的aware UTC时间；不是供应商POI更新时间，不等于内容新鲜度 |
| scope / applicable_scope | 查询上下文日期，不是供应商日期证据 | 同左 | 将其解释为调用方关心的目标日期；静态API未验证未来日期，另记date_support=not_asserted；不得据此声称指定日期已证实 |
| missing_fields | 服务端计算 | 服务端计算 | 仅使用既有district/address/coordinates/coordinates.crs/entrance枚举，依实际缺口填写，不把分页或许可缺口塞进此字段 |
| disambiguation | 省区/父子/类别线索 | 省区/类别/导航点线索 | 仅可读说明，≤5条；不得从文本中恢复授权/坐标角色/匹配分数等权威字段 |
| total_matches / items | count描述单次返回数；不等于全局匹配总数 | total受分页字段与上限影响 | 必须另述搜索覆盖/裁剪情况，不将一页一条等同唯一地点，详见下文 |
| outcome / error | 根status/info/infocode | 根status/message；注意根status和POI营业status不同 | 业务成功与空结果分别判定；API成功不等于身份匹配，更不等于VERIFIED |

坐标体系的通用官方说明见[高德坐标说明 A02](https://lbs.amap.com/api/javascript-api-v2/guide/transform/convertfrom)。该链接用于CRS语义，不授权使用JS转换或固定偏移算法。WGS84、GCJ-02、BD-09保持分离；百度米制BD09MC不能塞进经纬度字段。不得借试点增加地图展示或第三方坐标转换请求。

## 可信绑定与合成隔离

现有 `PlaceLookup` 固定SYNTHETIC_PROVIDER、environment=synthetic和合成名称/引用前缀；`PlaceObservation`只允许NON_LIVE且usable_for_real_trip=false。`SyntheticPlaceSource`没有live开关，内部UUID5来自本地合成目录。它们是有效隔离边界，不能删除约束或用字符串替换来创建真实来源。

后续须新建独立真实Adapter及其原始响应DTO；可信注册项至少包括provider/API版本、environment、能力、许可引用、允许字段/保留政策、host/path白名单、Key secret引用、账户配额及运行总上限。调用方只传PlaceQuery/ResourceRef，不能选择Key、host、environment或核验状态。源响应即使含provider/environment/evidence_id/VERIFIED，也全部按未知字段处理或丢弃，不能覆盖注册项。

拟议 `LivePlaceLookup` 应与现有离线类并存，记录新版本的未核验观察；接收时间、观测UUID、query摘要及provider绑定均在服务端产生。首轮状态只到SOURCE_UNVERIFIED，usable_for_real_trip仍false；**不复用NON_LIVE的PlaceObservation模型承装live**，也不自动接入完整EvidenceV2、旧Evidence mapping或确认预算。

## 需要先批准的契约差距

| 差距 | 当前行为 | 必要处理方案（本轮未实现） |
|---|---|---|
| 查询长度 | keyword允许100字符；高德仅80 | Adapter明确拒绝不支持长度并返回unsupported，不静默截断；百度3.0长度上限另核，不能照抄旧2.0上限 |
| 分页/匹配计数 | SourceResult的ok/partial要求total_matches=1；assess_identity可对单条完整结果SELECTED | 真实search增加版本化SearchCoverage/裁剪元数据，并强制显式候选选择+detail复核；搜索单条不产生SELECTED权威。缺覆盖信息时不谎填总数或伪造第二候选 |
| 数量文档差异 | query.limit允许1–20 | 百度3.0页大小写10–20，但部分返回name说明仍写最多10；须商务/技术澄清，首批按10请求，小limit通过本地裁剪并保留歧义/覆盖状态，不将裁剪结果当唯一 |
| 名称匹配 | keyword必须为name子串，否则REJECTED | 真实数据常见简称/别名；增加可审阅alias/匹配依据与人工选择流程，保留原名，不能改名骗过检查，也不能模型自动确认 |
| 行政区/分类 | 当前仅名称文本和单一category | 独立保留获权的编码与映射版本元数据；同名地区必须依据编码/层级绑定，不自动跨城合并 |
| 点的语义 | Coordinates未编码POI中心/引导点/入口角色 | 先保持entrance=null及部分事实；需扩展时另审coordinate_role/入口来源，现有CRS预检查不能代替入口核验 |
| 未来日期 | ApplicableScope仅起止日期 | 独立记录适用性未被来源证明；不能把当前静态查询结果当未来日期事实 |
| 真实内部资源 | 只有Synthetic目录映射，无真实注册表 | 试点可用获许可的进程内注册表；若需稳定跨重启ID，须先批准持久化范围和追加迁移，不复用正式Trip资源或临时名称哈希 |
| 详情复核 | PlaceLookup仅封装search；端口detail存在 | 新边界必须覆盖search和detail的环境/版本/ID/地区绑定，防止按旧UID取到迁移、合并或替换后的另一个实体 |

真实资源注册键建议为(provider, API版本, provider_resource_id)，映射到独立内部ID；相同外部ID若跨实体/城市/区县冲突，先隔离并人工复核，不改写已审阅映射。ID改名/合并/撤销需要版本和别名关系，不能假设厂商ID永久稳定。跨供应商同名候选默认不同实体，合并必须单独人工证据。

## 安全错误映射

下列为本地设计I，厂商错误语义参考[高德A09](https://lbs.amap.com/api/webservice/guide/tools/info)及[百度旧Web错误参考B02](https://lbsyun.baidu.com/docs/webapi?title=placev3/guide/webservice-placeapiV3/interfaceDocumentV2)，3.0具体码表须在实施前再核查。

| 外部情况 | 当前六类契约的安全结果 | 后续运行行为 |
|---|---|---|
| 成功且确实无POI | not_found，无items/观测 | 说明本次查询未找到，不能说地点不存在或已关闭 |
| 多个可能地点/入口 | ambiguous_resource | 明确要求选择，不取排名第一 |
| 根状态鉴权/服务权限错误 | unavailable，retryable=false | 记录脱敏内部auth_denied/permission_denied，停止该来源，提示人工检查配置 |
| 配额或并发超限 | unavailable | 内部quota_exceeded；首轮不自动重试、不换Key/供应商绕限 |
| 网络/HTTP超时 | timeout，无items | 有界退出，不使用Synthetic伪装真实fallback |
| 5xx/暂时故障 | unavailable | 可重试标识不代表自动执行；受统一预算与deadline约束 |
| 非POI类型或请求范围不支持 | unsupported | 百度行政区/地址等不强转PlaceCandidate |
| JSON/类型/字段/ID/坐标非法或绑定冲突 | schema_changed | 无宽松解析，不回显原始响应、Key、堆栈或URL |

适配后的地点身份尚未经过经营主体核对、入口核查、时间适用性和新鲜度核验；即使API根状态成功、detail ID一致、坐标数值合法，也只能是有来源的未核验观察。不能宣布营业、路线、门票、酒店、预算或真实旅行证据VERIFIED。
