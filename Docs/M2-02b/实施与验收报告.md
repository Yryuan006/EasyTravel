## 契约与确定性语义

`LegEndpoint` 绑定完整内部 ResourceRef（包括供应商资源、城市、区），要求 access_id 及 exit/entrance 角色；center 角色不在 Schema 中。Application 输入是服务端内部 DTO：resolved_endpoints 必须来自服务端已完成地点消歧/入口解析的注册表，不能由模型或外部请求自报。本轮不提供 HTTP API，不实现注册表解析服务。检查 pair 的活动地点、出口、入口及注册表精确相等；同一内部资源在注册表不能绑定不同 ResourceRef。身份错误 FAIL；其他入口、资源、leg_id 或反向事实不会被借用，返回 UNKNOWN / missing_matching_leg。

`ConsecutiveActivityPair` 显式包含前后活动、目标有向 Leg 与端点；由受信任调用者提供已经确定的相邻活动，不实现全行程排序、寻找相邻项或 F01 全行程覆盖检查。每个 pair 分别计算并保留报告结果。

`LegDuration` 的起点步行、终点步行、候车、换乘、乘车均为非负整数秒；0 表示显式已知无需该部分，null 表示未知。complete=true 必须五项齐全，合计为正且不超过 86400 秒；complete=false 即使五项有值也不能 PASS。完整交通时长仅为这五项之和，没有可任意覆盖的 total 字段。duration=null 也是 UNKNOWN。extra_buffer_included 固定 false；携带供应商已包含额外缓冲的事实必须先在未来可信规范化层拆分，本轮拒绝该标识为 true，避免重复计入或不透明减去。

附加缓冲独立计算：`max(600, ceil(total_seconds / 300) * 60)` 秒，相当于 `max(10 分钟, 向上取整到整分钟的 20% 完整交通时长)`。纯整数运算，无浮点舍入。规则版本 `F03-synthetic-v1`；缓冲版本 `M2-00-city-max600-ceil20pct-minute-v1`。候车、换乘已在完整交通时长内，不再额外叠加固定候车/换乘缓冲；该独立 20% 不确定性缓冲基于完整时长计算一次。

活动为 +08:00 的半开区间，end 必须大于 start；秒级精度保留，不将活动时间取整。next.start 大于或等于 previous.end + duration + extra_buffer 即 PASS，差一秒为 FAIL。活动已重叠是独立硬失败，即使缺路线时间也保留 FAIL 和 UNKNOWN。仅支持同城、同一天；活动跨日、交通或加缓冲后跨日返回 UNKNOWN，不声称跨日可行。非法时区或活动倒序/零长 FAIL。铁路/机场政策标记或跨城为 UNKNOWN / policy_scope_unsupported，不能使用普通城市缓冲作为接驳保证。

`LegApplicableScope` 为闭合日期范围加同日时间窗口，固定 Asia/Shanghai。窗口针对出发与完整交通覆盖：window_start <= previous.end < window_end，交通到达允许恰好等于 window_end；完整路线不得跨出窗口。独立内部缓冲不属于交通事实窗口。暂不支持跨午夜窗口，输入契约拒绝颠倒或零长窗口。

来源只允许 synthetic_travel_fixture / synthetic / SYNTHETIC_UNVERIFIED 和 synthetic-travel 引用。observed_at <= evaluated_at < expires_at 才新鲜；出行日期适用范围与观测 TTL 分开，TTL 不是出行日运营承诺。过期、未来观测、日期/时间窗口不符、时长不完整均 UNKNOWN。多个匹配来源任何一个依赖不确定即保留 UNKNOWN，不能挑选另一个来源升级；全部适用时五项时长构成不同也视为未消解冲突（即使合计相同），一致才进行算术。

`F03FeasibilityCheck` 保留 pair/leg/item 标识、完整端点、目标时刻、fact_ids、状态、原因、阻断级别、动作、完整交通秒数、额外缓冲、最早下一开始时间及双规则版本。报告记录注入的 aware clock、规范化输入 SHA256；按标识排序，输入集合换序不会改变结果。PASS 报告有效期取所用来源最短 TTL；其他结果不提供有效期。空范围为 NOT_APPLICABLE。Application 会重新验证嵌套输入，拒绝 model_copy/model_construct 绕过。

## 与 M2-00 F03 设计对应

| 正式设计要求 | 本轮实现及证据 |
|---|---|
| 相邻跨点时间公式 | check_pair 确定性计算，充足、不足、精确等于、差一秒测试；报告导出 required_next_start |
| from_exit/to_entrance 与服务端资源 | 完整 ResourceRef、角色及注册表精确绑定；入口、出口、内部地点、provider_resource_id 和方向反例 |
| 起终步行、候车/换乘、乘车 | 五个显式分量合计 2100 秒的虚构夹具；每个分量缺失均 UNKNOWN |
| duration 与 buffer 分离 | extra_buffer_included=false；600 秒最小值、3000/3001/3300/3301 秒取整边界测试 |
| 日期、窗口、来源、有效期 | LegApplicableScope、TravelLegSource；过期等号、未来观测、日期和窗口边界反例 |
| 不确定输入不得补成 PASS | 缺失/不完整/过期/冲突保守 UNKNOWN，不选择有利来源 |
| 独立 FAIL 优先并保留未知项 | 不足 pair 与独立未知 pair 聚合；同一 pair 重叠与缺事实并存 |
| CRS 不混用、不以距离证明交通 | 坐标仅描述字段，无计算/转换；四种 CRS/缺失坐标基准不能补出路线时间 |
| 外部文本不作为指令 | note 仅数据；中文指令、system 标签等不能改变不足时间的 FAIL |
| 合成事实不能自升权限 | VERIFIED/live/真实供应商/HTTP 来源输入均拒绝；report READY 恒 false |
| F03 不等于 F04 或整趟 READY | evaluated_checks 仅 F03，f04_status 固定 NOT_EVALUATED，三种真实行程/确认权限恒 false |
