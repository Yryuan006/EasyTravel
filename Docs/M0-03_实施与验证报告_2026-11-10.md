## API 契约与联通

仅请求现有 `/api/v1/health`。客户端以 unknown 解析网络输入，校验 `alive` / `http_application_liveness` / 三个 `not_checked` 字面量；支持归档 OpenAPI 中可省略字段的默认值。非 2xx 即使携带成功样式 body 也明确失败；非法 JSON、错误字段、超时、网络中断均有安全错误，不向页面回显原始内部异常。组件始终注明依赖就绪情况未验证。

浏览器使用相对 URL，经 Vite `/api` 代理访问 loopback FastAPI；默认目标 `http://127.0.0.1:8000`，可通过仅用于服务端配置的 `EASYTRAVEL_API_PROXY_TARGET` 改写。未引入 CORS 放开规则；未复制任何密码/API Key 到前端。生产静态部署必须另配同源 `/api` 反向代理，preview 不自带开发代理。

实测 FastAPI `http://127.0.0.1:8000/api/v1/health` 和开发服务器 `http://127.0.0.1:5173/api/v1/health` 均返回 HTTP 200：

```json
{"status":"alive","scope":"http_application_liveness","dependencies":{"database":"not_checked","model":"not_checked","travel_data":"not_checked"}}
```

Playwright 在真实 Chromium 中再次验证代理 HTTP 200、响应字段及页面成功状态。失败用例由浏览器拦截网络实现，不连接真实 LLM、生产数据库或外部预订服务。
